# KW Setups

- **Folder:** KW_Setups
- **Main category:** Action Bars. **More:** Miscellaneous.
- **Relations:** none.
- **Logo:** `standalone/logos/setups.png`

## Summary

Copy a character's action bars, keybindings, macros, Edit Mode layout, interface settings, chat text size and addon list to another character, with undo. A new character can start from a saved setup.

## Description

Setting up a new character's bars and keys by hand takes a while. KW Setups saves them once and puts them on any other character.

- Saves action bars, keybindings, macros, the Edit Mode layout, per-character interface settings, chat text size and the addon list.
- Places only spells the character knows, so another class's setup never puts its spells on your bars.
- A window shows which setup goes onto which character, then a check, warning or X for each part after you apply it.
- Applies only out of combat, only when you click Apply, and always saves an undo point first (`/kws undo`).
- Mark a setup Use For New Characters and a brand-new character (level 1, no experience, no money) gets it on its first login. Any other character is never changed without a click.
- Game settings shared by the whole account are left alone, since every character already has them.
- Every character that logs in gets an automatic setup. `/kws chars` lists them: untick a bank alt to leave it out.

`/kws` opens the window. Settings: Esc > Options > AddOns > KW Setups.
